Simple Docs!

Simple Docs! is a version of Google Docs designed for use among young kids, especially those in elementary school. It retains a lot of the core functionality of Google Docs — writing, formatting, sharing, and commenting — but wraps it in a more appealing and easy-to-use design built for children.

The login and welcome screens use friendly illustrations and large, simple fields so kids can sign in independently, while the editor keeps the essentials — bold, italic, underline, font and size controls, images, stickers, and shapes — front and center.

There are animations and colors everywhere, and no drop-down menus, which preserves convenience and lowers the learning curve for the app compared to a full-featured word processor built for adults.
