Roommate Court

Roommate Court is a full-stack web platform that turns roommate conflicts into a structured "courtroom" workflow, so instead of settling disputes out in a group chat, roommates file a case, present evidence, and get a resolution everyone agreed to up front.

I built dynamic React components to support case creation and evidence submission, including photo and text uploads, with real-time UI updates so everyone in the household sees the same state as a case moves through the process.

For resolving disputes, I implemented a jury-based voting system alongside an automated AI judge that generates a verdict from the submitted evidence and statements, giving households a fair, consistent way to settle disagreements without one person having to play referee.

Case tracking and historical records are powered by Firebase, so households can look back on past disputes, rulings, and accountability over time rather than re-litigating the same arguments.

I also created low and high fidelity mockups early on and translated them into the final UI flows, which kept the experience consistent across the whole app.
